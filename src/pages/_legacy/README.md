# Páginas legadas (fora do produto)

Arquivos mantidos apenas como referência histórica. **Não** estão registrados no router nem no menu (`productMenu.ts`).

Componentes e rotas legados equivalentes ficam em `src/components/_legacy/` e `src/router/_legacy/`.

Para reativar uma tela, implemente o backend correspondente e registre a rota em `src/router/AppRouter.tsx` e `src/config/productMenu.ts`.
